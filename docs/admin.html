About Net-monit V11.3

Net-monit V11.3 is a production-grade, self-hosted network and server monitoring platform. Monitor ping latency, packet loss, CPU, memory, disk, bandwidth and more across your entire infrastructure. Receive email alerts with configurable thresholds and multi-level escalation routing.

Export configuration

Downloads a single file with your devices (including credentials, still encrypted exactly as they're stored — restoring on a different machine also requires copying that machine's data/secret.key), SMTP settings, notification templates, custom placeholders, thresholds, and escalation settings.
Not included: alert/metric history, the audit log, speed test or network scan history (use a full data/monitor.db file copy for that), and this server's own port — restoring a backup never changes the port you're currently running on.

Restore configuration

Restoring replaces your current devices, SMTP settings, templates, custom placeholders, thresholds, and escalation settings with the contents of the file — this cannot be undone. User accounts are the one exception: imported accounts are added or updated, but any account not in the file is left alone, so you can never lock yourself out by restoring an older backup.
We strongly recommend downloading a fresh export of your current configuration above before restoring, in case you want to go back.
