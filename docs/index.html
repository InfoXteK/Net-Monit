1. Add monitors

Type an IP or URL, pick a device type and a check method, or scan a subnet and add what it finds.

2. Set thresholds

Warning and critical limits per metric, globally, per type, per method or per device. Sensible values are one click away.

3. Get alerted

Alerts confirm before firing, repeat politely, escalate to support and managers, and close themselves on recovery.

What it monitors

Each device gets one check method. The method decides what is measured.

MethodBest forWhat you get
Ping (ICMP)Anything with an IPUp or down, latency, packet loss
SNMPSwitches, routers, firewalls, printers, UPSAdds CPU, bandwidth, interface data, uptime, device type
PowerShellWindows serversCPU, memory, disk, Windows services, scheduled tasks
SSHLinux serversCPU, memory, disk, remote commands
Disk / Shared folderNAS, file serversFree and used space of a UNC or mounted path
HTTP / HTTPSWebsites and web appsStatus code, response time, DNS, TCP connect, SSL handshake, SSL days left, keyword match

Device types: Network device, Router, Switch, Firewall, Wireless AP, Windows server, Linux server, VMware host, NAS, Printer, UPS, IP camera, Other. The type decides the dashboard tab and which thresholds apply.

How alerting works

Built to avoid false alarms and alert fatigue.

Check. Each device is polled on its own interval (default 30 seconds).
Evaluate. Every metric is compared with its thresholds. The most specific rule wins: device override, then check method, then device type, then global, then built-in defaults.
Confirm. A problem must last the configured wait (default sustained) before an alert is sent. A device is only declared Offline after several failed checks in a row, with re-checks in between.
Notify. Level 1 goes to the admin group. Level 2 adds the support group, level 3 the managers, each after its own delay, by email, SMS and voice call.
Control. Acknowledge to silence repeats, Resolve to close, or let recovery close it. A recovery notice is sent. Every action is written to the audit log.

Install the real thing

Free. Runs on Windows or Linux. Source: github.com/MohamedAbdullahKhan/Net-Monit

Windows

Right-click Setup.bat, Run as administrator. A wizard installs the files, registers the Windows service and opens the dashboard.

Linux

chmod +x setup.sh
sudo bash setup.sh

Registers a systemd service.

Manual, any OS

pip install -r requirements.txt
python app.py

Port comes from NETMON_PORT or config.yaml.

First login

On first start Net-monit creates an admin account admin@email.com with a random token and saves it in data/FIRST-RUN-ADMIN-TOKEN.txt. Log in with it, then change it in the Admin Panel. The file is deleted at first login.

Honest limits of the demo

  • No real ping, SNMP, SSH, PowerShell, scanning, email, SMS or voice. All data is invented and resets when you press Reset demo or close the tab.
  • License keys are only format-checked here. The real app verifies the Ed25519 signature.
  • Logo and background uploads are not kept.
